## 0.2.0 · Tauri 界面迁移（2026-10-25）

- 界面已切换为 Tauri 2 + React 19 + TypeScript + shadcn/ui Base Nova，Rust 设备、渲染、服务、存储及进程隔离架构保留。默认构建内嵌静态前端，不依赖开发服务器或 Node。
- Windows x64 发布构建成功；Clippy 无诊断；29 项 Rust 单元／集成测试、10 项前端测试通过。前端覆盖编辑历史、保存队列、文件操作屏障、锁定保护、动态层限制和旋转几何。旧 egui 的两项 UI 测试由新的前端测试替代。
- 新发布二进制的模拟验收通过：三台／五屏、独立像素、三种输出格式和工作进程故障恢复。报告：`artifacts/tauri-selftest.json`。
- 实际 WebView2 桌面窗口检查通过：中文与时钟使用 Rust 画面，添加文字、修改内容、画布拖动、一步撤销／重做、自动保存；重启后场景与绑定保留。奶油白、深海蓝、属性／图层布局、设置弹窗及应用品牌已复核。
- 实际模拟屏绑定后约 30 FPS。关闭主窗口后发送计数从 6413 增至 6618、错误 0；再次启动只恢复一个窗口；完全退出后停止 UI、后台与设备工作进程。
- 修正了官方生成组件与当前 Base UI `data-orientation` 属性的样式适配，复核属性面板及滑块方向。
- 安装包检测 WebView2，缺失时通过微软签名的随包引导程序联网安装；便携包提供同一引导程序。缺失运行时的离线安装尚不支持；本机已有 WebView2，未测试运行时缺失分支。
- 本次界面迁移没有重新执行 LG600 实屏、四方向与两小时测试，以下真机结果仍为 0.1.0 后台的短时 USB 记录。
