# PixelFerry 验证记录

本文件区分代码实现、自动化检查与真实设备验收；尚未执行的项目不算通过。

## 垂直对齐与符号字号（2026-10-27）

- 文字、时钟、独立传感器和 DeepSeek 的文字样式新增“垂直对齐”：顶部／居中／底部，与左／中／右独立组合。`verticalAlign` 缺省为 `middle`，保持旧场景外观；超高段落保留顶部裁切行为。
- 混排传感器及金额参数增加可选 `affixScale`，范围 0.25–1，默认 1。解析器仅在参数有效且符号可见时，将单位／货币符号分成较小字号的绘制片段；数字保持参数字号，符号共用基线、字体、颜色与字重。隐藏符号或值过期时不会缩小数字和 `--`。
- 修复参数点击后的 DOM 选区、修改标签长度时的选区恢复、以及原子标签位于段尾时 Ctrl+Home／End 的边界定位；字段设置、复制、拖拽及中文组合输入回归通过。
- 43 项 Rust 测试、18 项前端测试通过：九种对齐组合像素定位、继承与覆盖字号、缩小符号与手写分段字号的逐像素等价、三种线格式、缺失数据、范围验证、旧配置缺省及场景包比例保存。Edge 模拟 API 检查覆盖选项切换、隐藏／显示、保存重载和带比例的结构化复制；截图 `artifacts/text-affix-controls.png`。真实 USB 显示待人工确认。

## 文字与动态参数混排（2026-10-27）

- 文字属性新增 Lexical 可视化编辑弹窗，支持普通文字和原子参数标签混排、搜索传感器、各段字体／字号／颜色／粗体、小数位、单位、货币符号、拖拽与结构化复制粘贴；外部粘贴按纯文字处理。弹窗内独立撤销／重做，应用为一次画布历史操作，取消不保存草稿；编辑时暂停背景编辑画布预览，草稿预览以 200ms 防抖、每秒刷新且单请求在途。
- `richText` 是可选版本化片段结构，前后端同步验证版本、256 片段、16000 字节及样式／格式边界。不保存 HTML、编辑器内部状态、凭据或采样值；纯文字与独立传感器／DeepSeek 保持兼容，支持转换与撤销。存储和场景包往返测试确认样式、稳定传感器 ID 及格式保留。
- Rust 统一解析传感器及 DeepSeek 六种指标，用 Skia Paragraph 分段样式排版；金额采用十进制定点舍入，独立处理缺失／过期与恢复。预览、JPEG、RGBA、RGB565 共用解析和渲染路径。编辑器按需加载。
- 40 项 Rust 测试、17 项前端测试通过，覆盖重复字段、Unicode／换行、继承和覆盖样式、金额舍入、币种、全部金额指标、过期恢复、像素等价、混合字号颜色、裁切、线格式与旧配置／场景包兼容；前端还验证画布／草稿请求串行及失败后队列释放。默认 `npm ci --dry-run` 验证锁文件一致。
- Edge 浏览器使用模拟 API 检查通过：光标中间插入、传感器搜索、分段样式、局部撤销、草稿隔离、参数删除／拖动／复制粘贴、切换来源、重载恢复、转换撤销和两种主题。中文组合输入通过 CDP 组合事件检查，不等同于 Windows 原生输入法人工验收。截图位于 `artifacts/rich-editor-1140.png`、`artifacts/rich-editor-1520.png`、`artifacts/rich-editor-dark.png`；模拟预览画布不计为原生渲染视觉验收。
- 独立配置的原生 `--self-test` 通过，`mixedText: true` 验证真实 IPC／工作进程输出与本地渲染逐像素一致；五屏、四方向和故障恢复同时通过，三个模拟设备错误数均为 0。日志 `artifacts/mixed-text-selftest.stdout.log`。本轮未执行真实 USB、真实 DeepSeek 账户或原生输入法人工验收。

## 安装方向旋转（2026-10-27）

- 输出渲染请求接入绑定的安装方向，按顺时针 0／90／180／270 度旋转完成的场景。90／270 度先交换逻辑画布宽高，再计算留边或裁切，最终输出仍保持屏幕原生尺寸；编辑画布保留场景自身坐标。
- 输出预览和 JPEG／RGBA／RGB565 帧共用旋转后的画面。LG600 硬件方向统一归零，防止固件再次旋转已旋转的 JPEG。
- 32 项 Rust 单元／集成测试通过，包括四方向逐像素比较、方形／横向尺寸、Contain／Cover、JPEG 解码颜色及 RGB565 编码一致性、防止重复硬件旋转。
- 独立临时配置的 `--self-test` 通过：五屏独立输出、后台连续切换四个方向的角标像素验证、工作进程故障恢复；报告 `installationDirections: true`，三个模拟设备错误数均为 0。日志位于 `artifacts/rotation-selftest.stdout.log`，本轮未连接真实 USB，也未确认实屏四方向效果。
